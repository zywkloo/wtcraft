# Worktree Task: Eliminate Duplicate Shell Script and Templates via Symlinks

## Objective
Replace the duplicate copies at `src/wtcraft/_shell.sh` and `src/wtcraft/templates/` with
relative symlinks pointing to the canonical sources at `scripts/wtcraft` and `templates/`
respectively. No logic or API changes.

---

## Context

| Location | Kind | Note |
|---|---|---|
| `scripts/wtcraft` | executable file (14977 bytes) | canonical shell script |
| `src/wtcraft/_shell.sh` | duplicate file (14977 bytes) | to become symlink |
| `templates/` | directory | canonical templates |
| `src/wtcraft/templates/` | duplicate directory | to become symlink |

`src/wtcraft/_cli.py` uses `os.path.isfile` / `os.path.isdir` which follow symlinks, so
symlinks in place of the real files/dirs are transparent to Python.  `os.path.realpath()` on
lines 25-26 will resolve symlinks to the canonical paths automatically.

setuptools follows symlinks when collecting `package-data`, so the entries in `pyproject.toml`
require no changes — pip will bundle the real file contents from the symlink targets.

## Scope — files touched

| File | Change |
|---|---|
| `src/wtcraft/_shell.sh` | delete file, create relative symlink → `../../scripts/wtcraft` |

- `src/wtcraft/_cli.py` — no changes (fallback logic is harmless; symlinks make it unreachable but it can stay)
- `pyproject.toml` — no changes needed
- `MANIFEST.in` — no changes needed
- `scripts/wtcraft` — canonical source, do not modify
- `templates/` — canonical source, do not modify

## Steps

1. **Verify current state** (read-only sanity check):
   ```bash
   ls -la src/wtcraft/_shell.sh src/wtcraft/templates
   diff src/wtcraft/_shell.sh scripts/wtcraft
   diff -r src/wtcraft/templates templates
   ```
   Both diffs must show no differences before proceeding.

2. **Replace `_shell.sh` with a symlink**:
   ```bash
   rm src/wtcraft/_shell.sh
   ln -s ../../scripts/wtcraft src/wtcraft/_shell.sh
   ```

3. **Replace `templates/` with a symlink**:
   ```bash
   rm -rf src/wtcraft/templates
   ln -s ../../templates src/wtcraft/templates
   ```

4. **Verify symlinks resolve correctly**:
   ```bash
   ls -la src/wtcraft/_shell.sh src/wtcraft/templates
   # _shell.sh -> ../../scripts/wtcraft
   # templates -> ../../templates
   readlink -f src/wtcraft/_shell.sh   # must point to scripts/wtcraft
   readlink -f src/wtcraft/templates   # must point to templates/
   ```

5. **Commit**:
   ```bash
   git add src/wtcraft/_shell.sh src/wtcraft/templates
   git commit -m "refactor: replace duplicate _shell.sh and templates/ with symlinks"
   ```
